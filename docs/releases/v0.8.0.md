# Koma v0.8.0 — prévia para Windows

## Navegação e desenho

- Na prévia do Animatic, aproximar mantém o ponto sob o cursor. Afastar traz a imagem de volta ao centro ao chegar a 100%.
- Arraste com o botão direito para mover a vista no Canvas, em Refs, na prévia e na timeline.
- No Animatic, o botão esquerdo usa a ferramenta selecionada. Alt + botão esquerdo e arraste ativa a borracha temporariamente. O modificador pode ser ajustado em Preferências → Atalhos.
- A roda do mouse e Alt + Shift + arraste voltam a controlar o zoom ao concluir ou cancelar um traço.
- O slider da timeline acompanha o zoom pela roda. Os botões de keyframe anterior e próximo saltam para o instante exato do keyframe no quadro atual.

## Referências e aparência

- Em Refs, use **Editar link** para associar um endereço à imagem. O ícone abre o endereço no navegador. A edição participa do histórico do projeto.
- **Cor de destaque** em Preferências → Aparência personaliza botões, ícones e outros controles do programa.
- O README agora guia a instalação e os primeiros passos no Koma.

## Instalação e projetos

No Windows x64, execute **Koma-0.8.0-windows-x64-setup.exe** ou extraia completamente **Koma-0.8.0-windows-x64-portable.zip** e abra `Koma.exe`. Os hashes dos arquivos estão em **SHA256SUMS.txt**.

O formato `.koma` passa para a versão 14 para guardar os links de referência. Projetos anteriores continuam abrindo. Guarde uma cópia do projeto original se precisar voltar à v0.7.0.
