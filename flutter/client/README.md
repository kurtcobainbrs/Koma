# Cliente Flet do Koma

Cliente desktop dedicado, compilado com Flet 1.0.5 e a extensão local `koma_drop`. Não contém Python embutido: usa o protocolo de URL, PID e diretório de assets do cliente Flet oficial, preservando a distribuição Python/PyInstaller existente.

Compilar e validar a partir da raiz: `python scripts/build_flet_client.py`.

O runner Windows foi gerado por `flutter create` 3.44.8. As fontes do Flutter são distribuídas sob BSD-3-Clause; dependências e avisos de terceiros acompanham a distribuição gerada pelo Flutter.
